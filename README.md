## 🌟 Project Overview

**BingePlay** is a data analytics project focused on understanding the performance of a fictional streaming platform using SQL and Python.

The project analyzes user subscriptions, sign-up trends, viewing behavior, content ratings, engagement patterns, subscription upgrades, and potential churn signals.

By combining **MySQL queries** with **Python and Pandas** in a Jupyter Notebook, this project transforms raw data into useful insights that can support data-driven business decisions.

## 🎯 Project Objectives

- 📈 Analyze monthly user sign-up trends.
- 💰 Evaluate active subscriptions and monthly revenue.
- 📱 Understand viewing behavior across different devices.
- ⭐ Explore content ratings and audience preferences.
- 🎞️ Compare platform originals with acquired content.
- 🍿 Identify binge-watching behavior and user engagement.
- 🔄 Analyze subscription upgrades and viewing patterns.
- ⚠️ Detect potential customer churn signals.

## 🔍 Key Analysis Areas

The project contains **12 SQL analysis tasks** covering the following areas:

1. 💵 **Active Revenue Analysis** — Examine active subscriptions and monthly revenue.
2. 📅 **Signup Momentum** — Identify monthly registration trends.
3. 📱 **Device Analytics** — Compare viewing sessions and completion rates across devices.
4. ⭐ **Rating Distribution** — Analyze audience ratings and positive reviews.
5. 🎬 **Originals vs. Acquired Content** — Compare content volume and average IMDb ratings.
6. 🍿 **Binge Day Detection** — Identify intensive viewing sessions.
7. 👀 **User Activation Analysis** — Find users who registered but never watched content.
8. 💳 **Subscription Value Analysis** — Identify potential mismatches between subscription plans and viewing behavior.
9. 🚀 **Upgrade Success Cohort** — Analyze subscription upgrades and time to upgrade.
10. 🔁 **Cliffhanger Comebacks** — Examine repeat viewing after incomplete sessions.
11. 📆 **Consecutive Week Engagement** — Measure sustained user engagement.
12. ⚠️ **Churn Signal Detection** — Identify users whose viewing activity has significantly declined.

## ⚙️ How to Run the Project

### 1️⃣ Install the required libraries

```bash
pip install pandas sqlalchemy pymysql jupyter
```

### 2️⃣ Set up the database

- Install and start MySQL Server.
- Create or import the `bingeplay` database.
- Ensure the required tables and datasets are available.

### 3️⃣ Open the Jupyter Notebook

```bash
jupyter notebook
```

### 4️⃣ Configure the database connection

- Enter your MySQL username and password when prompted.
- Update the host, port, and database name if required.
- Keep your database password private.

### 5️⃣ Execute the analysis

Run the notebook cells in order to execute the SQL queries and display their results.
